MedVoice,
Empowering the Elderly and Low-Literacy Patients through Visual & Audio Intelligence.
Developed for the Hack for Humanity Hackathon (2026)

 The Vision
In many communities, including my home in Iraq, elderly patients struggle with complex medication schedules. Language barriers, low literacy, and declining vision often lead to dangerous medication errors. MedVoice is a "No-Reading" solution that bridges the gap between the pharmacy and the bedside. It turns a standard tablet into a dedicated medical assistant that speaks to the patient and shows them exactly what to take.

 Clinical Foundation
I am a Nursing Graduate and a Health Informatics researcher. I built MedVoice because I’ve seen too many patients return to the ER simply because they couldn't read the instructions on a pill bottle. This app is designed with Clinical Safety and to increase physical health as the priority.

 Key Features
Nurse/Pharmacist Portal: Allows clinicians to input medication names, dosages, and schedules.
Visual Pill Recognition: Clinicians take a photo of the actual medication so the patient sees exactly what the pill looks like, not just a name.

Automated Voice Alerts: Using the Web Speech API, the app automatically speaks to the patient when it is time for a dose: "It is time for your heart medicine. Please take one pill after breakfast.

Real-time Cloud Sync: Powered by Firebase, ensuring that when a nurse updates a schedule, the patient's device updates instantly.

Offline Resilience: Uses localStorage to ensure reminders work even if the internet connection is unstable.
 Tech Stack
 
Frontend: HTML5, CSS3, JavaScript 
Backend: Firebase Firestore (NoSQL)
Intelligence: Web Speech API & AI-Assisted Logic

Hardware: Developed entirely on an Phone, proving that innovation is driven by problems, not expensive equipment.


Impact
MedVoice promotes Medication Adherence, reduces hospital readmissions, and provides independence to elderly patients who would otherwise rely entirely on caregivers.
